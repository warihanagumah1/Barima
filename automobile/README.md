# Barima Automobile & Transportation Services website

Static site, no build step. Open `index.html` in a browser to view it.

- `index.html`: the page (vehicle sourcing to Ghana, B-Drive rides in Ontario, FAQ, contact)
- `css/styles.css`: styles (navy #0B1F4B / red #D6202E brand palette)
- `js/main.js`: mobile menu, scroll animations, open/closed status, form handling
- `assets/images/`: photos cropped from the Barima flyer

The two forms open the visitor's email app with their details filled in
(vehicle requests go to barimaautomobile.ca@gmail.com, ride bookings to bdrive.ca@gmail.com).
To receive submissions directly instead, connect the forms to a service such as Formspree or Netlify Forms when hosting.

To deploy, upload the whole `automobile/` folder to the subdomain's web root.
